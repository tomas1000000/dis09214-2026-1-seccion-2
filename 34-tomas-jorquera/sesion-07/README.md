 ## ARRAY
 Un contenedor donde se almacenan datos de cualquier tupo bajo mun mismo nombre.
 Por ejemplo un array es un tren, y los vagones son cada elemento que puede contener, numeros enteros, variables e incluso otros arrays.
 Siempre se empieza a contar por el array 0, no el 1.
#### SINTAXIS: let NombreArray = [e0, e1, e,2, e3] ;
##### EJEMPLO: let colores = [ orange, red, yellow. blue] ;
 Para llamar a algunos de los valores de mi Array se utiliza: nombreArray [n° elemento]. Ejemplo (Colores[1])
